# ESG Auditor Network — Offline Prototype

## How to run
1. Extract `ESG_Auditor_Network_Offline.zip`.
2. Open `index.html` in Chrome, Edge, Firefox or another modern browser.
3. No internet connection, installation, server or account is required.

## Included
- Responsive desktop, tablet and mobile layout.
- Client marketplace: search/filter experts and submit consultation requests.
- Auditor portal: profile, availability and booking request workflow.
- Admin portal: dashboard, auditor verification, booking and user management, analytics.
- Sample data based on the ESG Auditor Network business deck.

## Important limitations
This is a front-end demonstration. It does not connect to a real database or implement real authentication, document uploads, email, payments, live messaging or production notifications. Changes are held in browser memory and may reset when the page is refreshed.

## Design direction
- Primary: #123D32
- Green: #32805D
- Surface: #EAF3ED
- Font: system UI / Inter fallback
- Responsive navigation and layouts
